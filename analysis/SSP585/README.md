# Recovered SSP5-8.5 modeling and figure workflow

This module preserves the recovered source calculations for V4 baseline maps (Fig. 3a/b), future projections (Fig. 7), niche comparisons and supporting figures. It is **not an independently verified complete historical rerun**: some HighT and response-plot source files were empty, and external inputs and historical versions are not bundled.

## Workspace and external environmental data

Set `THERMAL_PROJECT_ROOT` to a separate analysis workspace, containing `SSP585/NP_lowT/` and `SSP585/NP_highT/`. Set `THERMAL_BIOORACLE_ROOT` to an existing environmental-data directory with this layout:

```text
<THERMAL_BIOORACLE_ROOT>/
  biooracle_nc/                              # baseline surface NetCDFs
    terrain_characteristics.nc
    GLOBAL_grid_baseline_depthsurf_with_dist_km.tsv
  SSP585/2080_2100_timmean/                   # future surface timmean NetCDFs
    GLOBAL_grid_future_SSP585_2080-2100_depthsurf.tsv  # generated by LowT step7
```

The baseline global table must provide coordinates, baseline predictors and distance to land. Its original construction/download recipe was not recovered. Supply the correct Bio-ORACLE release, baseline 2000–2019 and future 2080–2100 SSP5-8.5 products, units and depth definition; these scripts do not acquire or version the environmental data. Future files are discovered by variable filename patterns in source. The future grid is shared by both ecotypes.

Training inputs may include restricted sample-level material. Obtain authorization and the source metadata via the data-access process described by the repository; do not commit these files. No sample records, environmental rasters, model objects or generated projection tables are released here.

## Ordered computation

Commands are shown relative to the code repository. Replace the environment values with actual external workspace paths. The pipeline writes intermediate tables and models back to that workspace.

```sh
export THERMAL_PROJECT_ROOT=/absolute/path/to/analysis-workspace
export THERMAL_BIOORACLE_ROOT=/absolute/path/to/environmental-data
Rscript analysis/SSP585/NP_lowT/R/step1_AOA_log10.R
Rscript analysis/SSP585/NP_lowT/R/step2_bio_oracle.R
Rscript analysis/SSP585/NP_highT/R/step2_bio_oracle.R
Rscript analysis/SSP585/step0_add_nearshore_filter_to_training.R
Rscript analysis/SSP585/NP_lowT/R/step3_pre_model_table.R
Rscript analysis/SSP585/NP_highT/R/step3_pre_model_table.R
Rscript analysis/SSP585/NP_lowT/R/step4_AOA_RF_pipeline_V0.R
Rscript analysis/SSP585/NP_highT/R/step4_AOA_RF_pipeline_V0.R
Rscript analysis/SSP585/NP_lowT/R/step5_AOA_future_cov_SSP_new.R
Rscript analysis/SSP585/NP_lowT/R/step6_AOA_future_projection_new.R
Rscript analysis/SSP585/NP_lowT/R/step7_make_GLOBAL_future_grid_from_nc.R
Rscript analysis/SSP585/NP_lowT/R/step8_GLOBAL_nearshore_projection_and_maps.R
Rscript analysis/SSP585/NP_highT/R/step8_GLOBAL_nearshore_projection_and_maps.R
```

This sequence requires a separately supplied **HighT step1 output** before HighT step2; its original source is missing. The missing HighT steps 5/6 concern sample-location future covariates/projections and are not reconstructed from the LowT implementation. Step8 independently uses the common global future grid.

| Stage | Main inputs | Main outputs / detail |
|---|---|---|
| LowT step1 | `NP_lowT/NP_lowT_coastal_abundance.xlsx` (rows genomes, `Genome` identifier, sample columns); `genome_lon_lat.xlsx` (`Genome` is sample ID, `Longitude`, `Latitude`) | `NP_lowT_sample_abundance.tsv`; sums the supplied ecotype genomes per sample and transforms abundance as specified in code. |
| Both step2 | Corresponding `NP_*_sample_abundance.tsv`; baseline surface NetCDFs | `AOA_points_with_BioORACLE.tsv` and an optional preliminary nearshore table. The preliminary table does **not** replace step0. |
| Shared step0 | Both all-point tables; terrain and baseline distance grid | `AOA_points_with_BioORACLE_nearshore_filtered.tsv` for each group. Requires depth ≥−200 m and distance ≤200 km; now stops if a group input is absent. |
| Both step3 | Nearshore-filtered table | `AOA_RF_V0_outputs/AOA_model_table_V0_final.tsv`. |
| Both step4 | Final model table | VIF/RFE, tuned caret/ranger model, importance, ensemble and partial dependence outputs in `AOA_RF_V0_outputs/`. |
| LowT step5/6 | LowT sample coordinates, baseline table and future NetCDFs | `AOA_future_cov_outputs/`; sample-level `AOA_pred_*_KEEPCHL_*` tables. |
| LowT step7 | Future depthsurf timmean NetCDFs | Common ocean-cell grid in the external future directory; geometry harmonization is preserved. |
| Both step8 | Nearshore-filtered training table; baseline global table; common future grid; terrain NetCDF | Ranger ensemble global projection and `GLOBAL_nearshore_pred_{current,future,delta}_nearshore200km_KEEPCHL_SSP585_2080-2100.tsv` in each group's `AOA_future_projection_outputs/GLOBAL_NEARSHORE_MAPS/`. |

Step4's tuned model and step8's independently fitted projection ensemble are distinct source implementations. Do not assume step8 loads `RF_tuned_model.rds`. Predictor requirements and missing-value handling are preserved, including required temperature/salinity/chlorophyll/silicate for KEEPCHL and conditional optional nutrients/oxygen. Historical results cannot be verified without exact inputs, predictor availability, software versions and stochastic settings.

## Figure and summary entry points

After producing or obtaining matching projection tables:

```sh
Rscript analysis/SSP585/FIG.R
Rscript analysis/SSP585/plot_Fig8e_area_weighted_latitudinal_contribution.R
Rscript analysis/SSP585/FIGS_V4.R
Rscript analysis/SSP585/niche_analysis_v2.R
Rscript analysis/SSP585/niche_analysis_supplementary.R
python analysis/SSP585/summarize_LowT_HighT_direction_pairs.py
Rscript analysis/SSP585/plot_LowT_HighT_revision2.R
Rscript analysis/SSP585/plot_LowT_HighT_revision2_supplement.R
python analysis/SSP585/analyze_lowT_environmental_context.py
Rscript analysis/SSP585/plot_LowT_environmental_context_supplement.R
```

- `FIG.R`: current/future/delta maps and change-class/global summaries. Plotting aggregates to 0.25° display cells. The original prediction-grid resolution depends on supplied rasters and is not changed here.
- `plot_Fig8e_area_weighted_latitudinal_contribution.R`: V4 Fig. 7e, despite historical filename. Back-transforms log10 predictions, weights by cosine latitude, reports latitude contributions and global future/current ratio.
- `FIGS_V4.R`: V4 Fig. 7f/g HighT future SST/chlorophyll sectors, at 22°C and 1.5 mg m−3. Cell occupancy is unweighted. Change classes use ±0.2 log10 units. Added checks require identical unique coordinate order before the original row-wise assembly. A mismatch stops execution rather than pairing unrelated rows. Here “ALE-informed” refers to **accumulated local effects**, not gene-tree reconciliation.
- `niche_analysis_v2.R` plus `niche_analysis_supplementary.R`: abundance-weighted SST, breadth, overlap and environmental heterogeneity (related to S6 and supplementary niche descriptions), from nearshore-filtered sample tables.
- Paired-direction Python/R scripts: coordinate-joined spatial divergence and threshold summaries (S13). Outputs start `LowT_HighT_` or `Fig_revision2_`.
- LowT environmental-context scripts: future-environment quadrant counts, source tables and supplementary plots (S17). Inputs are the projection delta tables, whose `temp` and `chl` columns are future covariates in step8.

Plot source names retain old figure numbering. Consult `docs/FIGURE_MAP.md` for the target paper mapping; standalone output layouts are not claimed to be byte-identical to the assembled manuscript panels.

## Dependencies, validation and gaps

R: `readr`, `readxl`, `dplyr`, `tidyr`, `stringr`, `tibble`, `terra`, `ncdf4`, `data.table`, `ranger`, `caret`, `car`, `pdp`, `ggplot2`, `patchwork`, `scales`, `sf`, `rnaturalearth`, `rnaturalearthdata` and dependencies. Python: `numpy`, `pandas`. Install dependencies explicitly before running. Original package, external-data and operating-system versions are not completely known. This release was checked for syntax and missing-root failure, not fitted again on restricted data.

The HighT original files `step1_AOA_log10.R`, `step5_AOA_future_cov_SSP_new.R`, `step6_AOA_future_projection_new.R`, and `step7_make_GLOBAL_future_grid_from_nc--no.R` were empty. The response/importance scripts under the original `compare/` directory were also empty, so the exact S16 permutation-importance/ALE/response-panel implementation is unavailable. Their empty placeholders are not published. No LowT script is passed off as an original HighT implementation. The precise S15 latitude-environment figure source and final full panel assembly remain to be reconciled. A complete automatic end-to-end rerun cannot be claimed until these gaps and input provenance are resolved.
