# Marine Nitrosopumilus ecotypes: selected methods overview

This documentation-only collection outlines selected analytical approaches used to study thermal differentiation in marine *Nitrosopumilus*. It describes the relationships between the main analysis components rather than providing an executable workflow.

The scope includes lineage abundance, phylogenetic and genomic comparisons, spatial and temporal validation, and climate-associated abundance projections. See [METHODS_OVERVIEW.md](METHODS_OVERVIEW.md) for a concise description.

## Scope of this collection

This collection contains explanatory text only. It does not distribute study datasets, sample-level metadata, reference sequence collections, analysis scripts, fitted models, parameter configurations, software environments, or runnable examples. It cannot independently reproduce the study's results and should not be cited as a complete code or data release.

The overview is not a substitute for the manuscript Methods, supplementary information, or separately approved data and code availability statements. Definitions and limitations are retained here to distinguish the analyses and their interpretation.

No claims about data access, repository accessions, or software availability are made by this collection beyond the files it actually contains.
