# Data access and input gaps

No real study data are bundled in this release. Module READMEs and `workflow/stages.json` describe the expected filenames, fields and stage roles. The presence of a source file in the authors' working directory is not evidence of permission to distribute its data.

| Material | Access route | What remains necessary |
|---|---|---|
| Qingdao 60-week observations | Request access from the study's corresponding author/data owner, identifying V4 Fig. 3d / S8 and the intended use. Permission is required before redistribution. | Approved abundance tables, real sampling dates/weeks, station metadata and environmental measurements. These inputs are currently withheld; no public download or access guarantee is claimed. |
| Kuroshio–Oyashio observations | Request access from the corresponding author and original dataset owner for V4 Fig. 3c / S7. | Approved matched sample-level abundance/environment tables, station and depth metadata. Currently withheld. |
| Temperature-incubation reads | The manuscript declares BioProject **PRJNA1526352**. Query the sequence archive by accession and verify its public status. | Public availability was not independently confirmed for this code release. The processed abundance table, treatment/time metadata and read-to-table workflow are also required; the accession alone is insufficient. |
| Public genomes and metagenomes | Obtain records from the archives named in the manuscript/supplementary data, using assembly/run accessions and versions. | A frozen, machine-readable accession list, sequence checksums and the matching sample/cohort map have not been bundled. Ask the authors for the V4 manifest. Do not substitute newly retrieved versions silently. |
| Ocean nitrification observations | Retrieve the Tang et al. (2023) database from the original publication's data record. For the audit, retrieve the original Tolar event data (the source names BCO-DMO dataset 774848). | Exact source URL/version/checksum and unchanged worksheet headers must be reconciled with the V4 source record; these are access routes, not completed downloads or verified version manifests. |
| Environmental grids | Obtain the cited Bio-ORACLE baseline/future layers and the terrain/distance products from their original distributors. | Exact model/layer, depth statistic, resolution, units, scenario, baseline/future periods and download checksums. See SSP585 README for layout. No grid or NetCDF is bundled. |
| Functional annotations | Generate or obtain the matching family memberships, gene/KO tables and annotation outputs under the original tools' and databases' terms. | Exact database releases, gene-family identity crosswalks and matched genome metadata. No KEGG/KOfam/other database redistribution is implied. |
| ALE events | Obtain every original family `.uml_rec` from the designated ALE_2 run and the rooted tree used in that run. | Original files containing the numbered `S:` tree were not found. Precomputed DTLO counts or a mapping derived from a different run do not close this gap. |
| Codon-model results | Regenerate from approved sequences/trees using the provided code, or obtain the matching original alignments, control files and full codeml outputs. | Foreground membership, model starts, convergence records, annotation results, historical tool versions and candidate integration input. |
| Figure authoring assets | Request the final editable composites/schematics from the authors. | Final Fig. 2a assembly, dating/palaeotemperature composite, incubation schematic and other exact layout assets are not fully covered by analysis scripts. |

For an access request, provide the figure/stage, exact filenames or schemas from its README, proposed scientific use and required access period. Ask whether access requires a data-use agreement and whether derived outputs may be shared. No contact address, approval timeline or unrestricted-access promise is invented here. Use the corresponding-author details in the manuscript or contact the repository owner to identify the responsible data custodian.

After access is granted, keep inputs in a separate workspace. Record source accession/URL, version, retrieval date, authorization scope and SHA-256 hashes in a private input manifest. Check that group definitions, tree tip IDs, genomic coordinate systems, time units and response definitions match the selected stage. Do not upload the completed private manifest if it contains restricted sample identifiers or access details.
