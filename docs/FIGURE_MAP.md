# Manuscript figure and analysis map

This map follows the V4 manuscript and its figure captions. It describes the available code collection and known gaps, not a verified complete reproduction. Historical script names retain earlier figure numbers; they do not define the numbering in the manuscript. A code path identifies an analysis entry point, not evidence that the complete analysis has been rerun successfully. Execution status and required inputs must be checked separately.

Restricted study datasets are not distributed. Full reproduction requires the corresponding authorized inputs, original tool outputs and database releases. Supplied summary tables, when available, support a downstream redraw; they do not replace upstream read recruitment, model fitting or phylogenetic inference.

## Boundaries that affect a complete rerun

- The current manuscript distinguishes the representative-genome phylogeny, the broader ALE tree, the population-genomic reference genomes and gene-specific trees. Do not interchange their node numbers, genome sets or coordinates.
- ALE crown labels require direct same-run verification. No inherited hard-coded numeric branch assignment should bypass that check.
- Restricted regional and temporal observations must be acquired through their data owners. Do not describe their presence in an internal working directory as permission to redistribute them.
- External genomes, metagenomes, environmental layers and annotation databases need an accession/layer manifest and version or checksum records. A methods citation alone is not a complete download specification.
- Manually assembled figures and schematics may require authoring assets in addition to analysis code. Exact layout reconstruction and recalculation of the underlying results are separate checks.
- Historical demonstration scripts and synthetic examples are not replacements for the final manuscript analyses. Any unresolved source matching or unavailable input must remain visible in the reproduction status.
