# Known reproduction gaps

This document records the limits found while locating and reviewing available V4 sources. It does not establish that the entire scientific analysis is invalid, nor does source syntax establish that its numerical results are correct.

- **Restricted observations:** the regional and 60-week inputs remain external, approval-dependent requirements.
- **Phylogeny and ASR:** the original marker/TOME/tree-inference recipes and final Fig. 2a tree–abundance–96-sample heatmap assembly were not located. The recovered ASR source uses four states; its equivalence to the V4 binary-state analysis is unresolved. A script consuming preassigned groups does not infer those groups.
- **Genome traits:** the exact eight-trait mean-scaled YAS radar source was not found.
- **Dating:** original MCMCTree controls, calibration/inference workflow and the exact final composite remain missing. A dated-tree display is insufficient to repeat inference.
- **ALE identity:** original same-run `.uml_rec` outputs were not found in ALE_2. Event extraction now requires those originals and verifies clade/branch identity. Prior numerical assignments are not embedded as verified biological labels.
- **Population metrics:** the legacy Fig. 5 pN/pS column is provenance-blocked; the available source audit identifies an uncorrected nonsynonymous/synonymous count ratio rather than opportunity-corrected pN/pS. A valid replacement requires gene-level opportunity counts and an explicit analysis revision. It is not silently substituted here.
- **FST:** a nonexistent scikit-allel function call was repaired using the ratio of window-summed Hudson components. The source filters were retained. The original manuscript values still need reconciliation with this repaired implementation.
- **Selection:** original fitted outputs, the candidate integration table, full tool/database versions and annotation inputs remain required. Main-panel separate-foreground ratios and supplementary direct-model tests must not be interchanged.
- **Climate code:** HighT step1/5/6/7 and several comparison scripts were empty. Usable scripts were retained; empty placeholders were omitted and recorded in the stage inventory. HighT steps were not invented by copying LowT code. Exact final S15/S16 and some composite layouts are not established.
- **Rate scaling:** the recovered conditional-scaling source retains an unresolved temperature-statistic mismatch flag. Its prepared-grid inputs and complete upstream generation chain are not bundled. Later source-pair audits do not transform it into a validated forecast of future ammonia oxidation rates.
- **Environment:** historical software/database lockfiles were not found. Present local version inspection and syntax checks are not historical-environment recovery.

Some missing requirements are public inputs that can be reacquired; others require authors' metadata, original output provenance or new source reconstruction. Record these as separate operations and revalidate manuscript-level totals and figures after they are supplied.
